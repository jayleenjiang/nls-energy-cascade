# Exact discrete path-ratio FT control

This experiment isolates the fluctuation relation from the two limitations of
the earlier NESS pilot: an estimated stationary endpoint density and an
unsupported `k <-> 1-k` rare-event pair.

The sampler starts independent trajectories from an explicitly normalized
product complex-Gaussian density and runs both the forward split integrator and
its conjugate reverse integrator.  Every stochastic bath substep contributes
its exact Gaussian transition-kernel log ratio.  The implicit-midpoint
Hamiltonian map is reversible and volume preserving, so it has no path-action
term.

Build and self-test:

```sh
clang++ -O3 -mcpu=native -std=c++17 -Wall -Wextra -Wpedantic \
  -Xpreprocessor -fopenmp -I/opt/homebrew/opt/libomp/include \
  -L/opt/homebrew/opt/libomp/lib -lomp \
  flux/NLS_discrete_path_ft.cpp -o flux/discrete_path_ft

./flux/discrete_path_ft selftest
```

Example run and audit:

```sh
./flux/discrete_path_ft sample 10 2 2 200000 0.1 0.001 1.5 \
  2026082802 8 experiments/discrete_path_ft_2026-08-28/production/driven

python3 flux/analyze_discrete_path_ft.py \
  experiments/discrete_path_ft_2026-08-28/production/driven_forward.csv \
  experiments/discrete_path_ft_2026-08-28/production/driven_reverse.csv \
  --output-dir experiments/discrete_path_ft_2026-08-28/production/analysis
```

The exact finite-step observable is not silently identified with bath heat.
Both are saved, and timestep convergence determines whether their difference
is negligible in the continuous-time interpretation.

## Version note

The exploratory files in `pilot/` and `diagnostic/` were generated by a v1
reverse driver that applied `H_-dt` after already time-reversing the state.
That reverses the Hamiltonian part twice.  They are retained for provenance
but are invalid for the reverse IFT.  Version v2 uses `H_+dt`, adds a
conjugate-path recovery self-test, and is the only version eligible for the
production conclusion.  Files in `pilot_v2/`, `diagnostic_v2/`, and
`production_v2/` use the corrected dynamics.
