\begin{abstract}
We re-evaluate the fine-timestep three-mode NESS estimator with exactly the
three-moment exponential calibration required by the coarse replication.  No
neural weight is retrained and no trajectory, split, shrink factor, normalizer,
or gate is changed.  Fine validation and the declared final test pass, the
equilibrium known-answer control passes, and the resulting three-moment
fine/coarse centered log-density RMS remains 0.0244 against the frozen 0.10
threshold.  The procedural asymmetry between timesteps is therefore removed.
\end{abstract}

\section{Frozen procedure and test access}

For each base seed $8201,8202,8203$, the fixed neural correction is augmented
by an exponential tilt in
\[
 I_1,\qquad I_1I_2\sin\theta_1,\qquad I_2I_3\sin\theta_3.
\]
The unshrunk coefficient vector is fitted on exactly the already opened rows
used by the prior fine calibration and then multiplied by 0.625.  The new V6
validation and test trajectories do not enter the fit.  Before any R11 value
was read, the protocol authorized one additional and final test access only if
driven and equilibrium validation both passed.  Both passed; their hashes were
then recorded before the test was opened.  All prior two-moment artifacts are
retained.

\section{Timestep replication under an identical protocol}

The three-moment fine/coarse ensemble centered log-density RMS is
\[
 0.024355\quad\text{on fine support},\qquad
 0.024353\quad\text{on coarse support}.
\]
Both pass the 0.10 gate.  The previous two-versus-three-moment values were
0.024257 and 0.024272, so the change is $9.8\times10^{-5}$ and
$8.2\times10^{-5}$.

\section{Equilibrium control and verdict}

The same three-moment model class is used with zero base correction and zero
calibration coefficients.  On test, ESS is 1, FP median is
$8.88\times10^{-16}$, FP p90 is $3.55\times10^{-15}$, maximum moment
$|z|=1.272210$, maximum TV is 0.033212, and seed disagreement is zero.  This
checks the operator, diagnostics, and sampled Gibbs control; because $f=0$
is imposed, it does not test the learned nonequilibrium correction.

The R11 result is PASS.  Both timesteps now use the identical three-moment,
0.625-shrunk calibration protocol.  The warranted claim remains a numerical
NESS density on sampled stationary support, not global control in unsampled
tails or an analytic stationary solution.
