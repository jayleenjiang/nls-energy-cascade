# Targeted EDMD oscillatory-mode extension

Analysis-only extension of the three-mode EDMD audit. It reuses the controlled
trajectories and adds one predeclared set of raw-action and action-angle cross
features. The targeted basis exposes a candidate near the known oscillatory
frequency, but the frozen four-case completeness gate fails because the driven
`dt=1e-3` dictionary spread is too large. The leading visible real rate also
moves from about `-0.95` to about `-0.91`.

Start with `report/edmd_oscillatory_extension_report.pdf`, then
`FINAL_VERDICT.md`, `VALIDATION_REPORT.md`, and `DELIVERY_CONTENTS.md`.
