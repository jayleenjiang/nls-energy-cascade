# Action-profile manuscript revision

This package revises only the action-profile portion of Section 3.1 in the
user-provided `paper_draft (1).tex`. The original file is preserved unchanged
under `source_snapshots/`.

## Deliverables

- `paper_draft_action_profiles_revised.tex`: revised full manuscript source.
- `Figures/action_profile_atlas.{pdf,png}`: all 36 stationary action profiles.
- `Figures/action_midpoint_scaling.{pdf,png}`: normalized midpoint scaling.
- `scripts/plot_action_profiles.py`: deterministic figure-generation script.
- `data/profiles/`: the 36 merged profile CSVs used in the atlas.
- `data/figure_profile_inventory.csv`: one row for every plotted profile.
- `data/figure_midpoint_source.csv`: source values and fitted slopes for the
  midpoint figure.
- `data/`: frozen protocol, run matrix, commands, validation report, logical
  run summary, scaling table, and equal-temperature checks.

## Evidence boundary

The full profile dataset was generated by the corrected-noise inherited SIMD
implementation and passed its BC1 endpoint-reproduction gate. It did not pass
the requested equal-temperature bond-sine control. The revised prose therefore
uses the data as finite-size evidence for the contrast between global and local
boundary drifts, not as a high-accuracy verification of Gibbs invariance.

The old high-sample BC1 profiles are retained under
`data/legacy_bc1_references/` as reproduction references. They are not replotted
as independent experiments because the new comprehensive dataset already tests
and reports their endpoint agreement.

two files were not included in the download or found in the local repository.

replaces those two absent files with labeled boxes. No placeholder is present in
