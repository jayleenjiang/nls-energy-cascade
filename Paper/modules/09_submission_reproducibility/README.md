# Module 09: reproducibility and submission materials

## Scope

This module contains numerical provenance, claim audits, reference checks,
source packaging, and journal-submission preparation.  It does not create new
scientific evidence.

## Main artifacts

- Paper/revision/source_trace_metrics.json: hashes and recomputed numerical
  metrics.
- Paper/revision/manuscript_claim_audit.md: registered claim checks.
- Paper/revision/raw_data_archive_manifest.md: exact raw files needed for a
  reproducibility archive.
- Paper/revision/reference_integrity_audit.md: citation-key and metadata checks.
- Paper/revision/submission_checks_summary.md: local submission gate.
- Paper/packages/NLS_best_current_2026-07-21: frozen compile package.

## Important path warning

Several June reports still print Paper/revision_2026-06-19 because that was the
directory name when they were generated.  The live local source tree is now
Paper/revision.  Treat old absolute/relative path text as historical metadata,
not as a command to restore or delete files.
