# Module 00: manuscript versions

## Scope

This module prevents the advisor-facing baseline from being confused with the
locally enhanced manuscript.

- Advisor-facing snapshot: draft_advisor_synced_2026-08-25.tex.
- Enhanced reference supplied for comparison: main_enhanced_reference_2026-08-25.tex.
- Active local enhanced manuscript: Paper/revision/draft.tex.
- Best frozen compiled package: Paper/packages/NLS_best_current_2026-07-21.

## Editing rule

Scientific content moves from the enhanced line to the advisor-facing line only
after its code, data, result, and advisor status are recorded in the relevant
module.  Do not edit frozen packages in place.

## Backup

The two supplied TeX files and the pre-organization repository README are
preserved under Paper/backups/2026-08-25_repo_organization.
